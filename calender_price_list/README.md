# Calendar Pricelist

Odoo 18 calendar for creating and editing pricelist rules from Sales and Point of Sale.

## Installation

Place `calender_price_list` in your addons path, update the Apps list and install
**Calendar Pricelist**. For an existing installation, upgrade the module.
Sales Management and Point of Sale are dependencies.

Enable Pricelists in Sales settings. Open **Products > Calender Price** in Sales
or Point of Sale. Select an empty date to create a rule, or an existing entry to
review and edit it. Confirm both validity dates before saving.
